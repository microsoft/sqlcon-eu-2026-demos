# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities, credentials, or sensitive data in a
public issue or discussion. Contact the repository maintainers privately through
GitHub with a description of the issue, affected files or components, and steps
to reproduce it.

Do not include live credentials, customer data, or other secrets in the report.
The maintainers will acknowledge the report, investigate it, and coordinate any
necessary remediation before public disclosure.

## Scope

This repository contains conference demonstrations and sample deployment assets.
It is not a supported production product. Before using any sample, review its
configuration, permissions, network exposure, cost controls, and cleanup steps
for your environment.
